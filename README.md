# SafeReturn – Lost and Found Web System

SafeReturn is a Flask-based Lost and Found web application that allows users to report lost and found items, communicate via item-based chat, and receive notifications. An admin dashboard is provided for managing reports, items, logs, and chats.

---

## 📌 Features

- User registration and login
- Report lost and found items
- Item-based chat system
- Real-time notifications
- Admin dashboard (Reports, Items, Logs, Chat)
- MongoDB Atlas integration
- Image upload support

---

## 🛠 Tech Stack

- **Backend:** Flask (Python)
- **Database:** MongoDB Atlas
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git & GitHub
